# SS2 & SS3 Tutorial Questions

A lightweight static site for viewing and downloading the SS2 and SS3 past-question PDFs.

## Pages

- Home: `https://YOUR-USERNAME.github.io/zmak-tutorial-questions/`
- SS2: `https://YOUR-USERNAME.github.io/zmak-tutorial-questions/ss2`
- SS3: `https://YOUR-USERNAME.github.io/zmak-tutorial-questions/ss3`

Replace `YOUR-USERNAME` with your GitHub username. The site uses GitHub Pages project-site paths and does not require a build step.

## Publish with GitHub Pages

1. Push this repository to GitHub as `zmak-tutorial-questions`.
2. Open the repository **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. Once the deployment finishes, open the Pages URL shown in the repository settings.

The PDFs are stored in `pdf/`. To replace a paper, keep its existing filename (`ss2.pdf` or `ss3.pdf`) so the viewer and download links continue to work.
